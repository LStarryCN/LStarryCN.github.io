## 记录方式

文章会尽量保留问题背景、思考过程与可运行的代码。例如，一个最小的 C++ 程序：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, LStarry!\n";
    return 0;
}
```

需要描述复杂度时，也会使用数学公式：

$$
T(n) = O(n \log n)
$$

> 写下来，是为了让思考可回顾，也让学习过程更连续。
